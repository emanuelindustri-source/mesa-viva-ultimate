# v0.1.0 — Fase 0: Fundación

**Fecha:** 14 de noviembre de 2026
**Estado:** Entregada
**Tipo:** Infraestructura y base técnica

## Objetivo

Crear desde cero la base del monorepo de Mesa Viva Ultimate: estructura de paquetes,
TypeScript estricto, pruebas automáticas, integración continua, despliegue en GitHub
Pages y sistema de notas de versión.

## Entregado

- Monorepo **pnpm workspaces** con 6 proyectos: cuatro paquetes (`core`,
  `design-system`, `engine-25d`, `sensory-engine`) y el cliente (`apps/client`).
- **TypeScript estricto** compartido (`tsconfig.base.json`) con `strict`,
  `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes` y comprobación de
  variables sin usar.
- **Motor Core inicial:** RNG determinista Mulberry32 con semilla, base de las
  partidas reproducibles; tipos `GameSummary` e identificadores de catálogo.
- **Design System inicial:** los 6 formatos de pantalla y las 19 festividades más
  el modo Día Normal, verificados por prueba.
- **Motor 2.5D inicial:** matemáticas de vectores (`clamp`, `lerpVec3`) y tipos del
  espacio de mesa.
- **Motor sensorial inicial:** las 4 primitivas hápticas y los perfiles de gestos.
- **Cliente Preact + Vite:** Landing provisional responsive con estado de fases,
  versiones de los motores e historial de versiones.
- **Calidad:** Biome para lint y arreglos seguros, Vitest para pruebas.
- **CI/CD:** `ci.yml` (lint + build + test), `deploy-pages.yml` (GitHub Pages) y
  `android.yml` preparado para la Fase 6.
- **Documentación:** `AGENTS.md` con las reglas del proyecto, `docs/arquitectura.md`,
  `docs/fuentes-reglas.md` y el sistema cronológico de notas de versión.
- **Git:** repositorio inicializado en la rama `main` y remoto público configurado.

## Decisiones técnicas

- **pnpm 12** instalado vía npm global porque `corepack` no tenía permisos sobre
  `C:\Program Files\nodejs`. Se documenta para futuras sesiones.
- **Preact** en lugar de frameworks más pesados para garantizar arranque inmediato
  y margen frente al límite de 10 MB.
- **Vite** con `base: '/mesa-viva-ultimate/'` para GitHub Pages; la app `/play/`
  se añadirá en la Fase 5 sobre esta misma base.
- `allowBuilds: esbuild` autorizado explícitamente por la política de pnpm 12.
